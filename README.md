# Rush 1 — ASCII Pattern & Box Renderer

> **Geometric shape and frame drawing routines in C.**

## Overview
Implements procedural square and rectangular frame renderers (`rush-1-1` through `rush-1-5`) using configurable border, corner, and fill ASCII characters.

## Build & Usage
```bash
gcc -o rush1-1 rush-1-1/*.c
./rush1-1 5 3
```
