> **Rush 1 is a collection of procedural 2D box drawing routines** (`rush-1-1` through `rush-1-5`) rendering rectangular frames with distinct border characters.

---

## ⚙️ Implemented Variations

- `rush-1-1`: Rectangles with `'o'` corners, `'-'` horizontal edges, `'|'` vertical edges.
- `rush-1-2`: Rectangles with `'/'` and `'\'` diagonal corners, `'*'` edges.
- `rush-1-3`, `rush-1-4`, `rush-1-5`: Variants rendering customized corner characters (`A`, `B`, `C`).
